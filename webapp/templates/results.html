Understanding Statistical Significance

p-value: "If there were really no difference between treatment and control, how surprising would this data be?" When the p-value is smaller than our threshold α (for example 0.05), we say the result is statistically significant and reject H₀ the "no difference" hypothesis (aka null hypothesis).

95% confidence interval (aka CI): The 95% confidence interval for (treatment − control) is a range of effect sizes that are plausible given the data. If the entire interval is above 0, the treatment is likely better. If it is below 0, the treatment is likely worse. If it crosses 0, the data are compatible with "no real difference," and any true effect is likely small and somewhere inside that range.

Understanding SRM (Sample Ratio Mismatch)

What is SRM? SRM (Sample Ratio Mismatch) checks whether your randomization is working correctly by verifying that the actual split of users between control and treatment matches what you expected.

Example: If you designed a 50/50 split and got 1000 users, you expect ~500 in each group. If you find 450 in control and 550 in treatment, this mismatch could indicate a problem.

Why it matters:

  • If randomization is broken, your experiment results are invalid
  • Even if you see statistical significance, you cannot trust it
  • Common causes: buggy assignment logic, biased user filtering, technical issues, bot traffic

The test: Uses a chi-square test to check if the observed split differs significantly from expected. If p-value < 0.05 → SRM detected → ⚠️ Investigation needed before trusting results.

✅ Passed: Your randomization is working as expected. Proceed with confidence.

⚠️ Failed: Stop and investigate! Don't trust your A/B test results until you fix the randomization issue.
